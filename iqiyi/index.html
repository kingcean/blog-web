iQIYI Windows client app

iQIYI is a video streaming platform with movies, TV series, shows, etc.

iQIYI Windows client app is a classic Win32 application to provide the mainstream services and native experience.

iQIYI - Microsoft Store page

Milestones

  • 2016Introduce RND, a self-developed React Native for Windows framework.
  • 2017 May* Join and lead the product and services.
  • 2018Merge PPS sub-app and iQIYI sub-app into one.
  • 2022 SepIntroduce LWA, a framework developed by iQIYI and Microsoft.
  • 2023 DecRefactor official and streaming website to re-use same technology and bundle.
  • 2024 H1RND is removed.
  • 2024 Sep* Left the R&D team of the product and services.

Notes

  • There were 2 sub-apps before - one is called PPS and another is called iQIYI.
    After merging, it has 2 theme mode: the style of original PPS is classic dark, and the style of original iQIYI is youth bright. And 2 years later, only dark mode is available to create an atmosphere of watching video.
  • RND is a web native framework to enable Type Script developing.
    The framework itself is developed by C++.
  • LWA is a new hybrid framework with local H5 runtime based on Microsoft Edge WebView2. It enable Type Script developing with full H5 experience.
    Microsoft Edge WebView2 id developed by C++; the LWA runtime is developed by C# for first version, and by C++ for the version in iQIYI Windows client app.
